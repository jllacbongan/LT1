# Calculating the information about a garden

## Description

This Python program calculates the information about a garden using functions
from the math library.

## How to Run
- Download the file and open it in PyCharm
- Run the python file
- Enter the required radius
- Wait for the calculated information to be displayed

## Input Needed

Enter the following input:

- radius

## Sample Output
**Input**

- Enter the radius: 5

**Output**
- "The area of the garden is 78.54 square meters."
= "The circumference of the garden is: 31.42 square meters."
= "The Square Root of the garden is: 8.86"
- "The Rounded Down Area is: 78 square meters"
- "The Rounded Up Area is: 79 square meters"
